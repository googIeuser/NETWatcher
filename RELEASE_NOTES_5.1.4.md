# NetWatcher 5.1.4

This update restores the solid interface and removes the experimental glass effect. It fixes the theme selector's unreadable option in light mode and gives the network map a matching light palette. Dark mode keeps its original map appearance.

The monitor now avoids snapshot polling while paused, follows the configured measurement interval while active, and reduces repeated gateway discovery and in-memory chart history. This lowers idle CPU use and default memory use without changing the saved measurement history.
