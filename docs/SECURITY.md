# Security Policy

## Supported versions

Security fixes target the latest published stable release. Older versions are not maintained separately; update before reproducing a report. The current stable version is listed in the [README](../README.md) and [releases](https://github.com/googIeuser/NETWatcher/releases/latest).

## Reporting a vulnerability

Use **[Security → Report a vulnerability](https://github.com/googIeuser/NETWatcher/security/advisories/new)**. Private vulnerability reporting is enabled for this repository. Do not open a public issue or pull request containing exploit details, credentials, or information that could put users at risk.

Include:

- The affected NetWatcher version or commit, Windows version, and installation type.
- Impact and the smallest reproduction using synthetic data.
- Expected and actual behavior, relevant sanitized evidence, and any proposed mitigation.

Do not include private network addresses, hostnames, account details, certificates, or private keys. Diagnostics ZIPs, ISP evidence reports, outage histories, and screenshots may reveal identifying network information; share only the relevant sanitized excerpts. If the private form is temporarily unavailable, open only a non-sensitive issue asking for a private channel and keep vulnerability details private.

## Coordination

Musa ([googIeuser](https://github.com/googIeuser)) reviews reports as time permits and coordinates investigation, fixes, and disclosure through the advisory. Please keep details private while the report is assessed. There is no guaranteed response or resolution deadline.

Ordinary bugs and usage questions belong in [SUPPORT.md](SUPPORT.md). NetWatcher's data storage and network requests are described in [PRIVACY.md](PRIVACY.md). Release checksums verify file consistency, not publisher identity.
