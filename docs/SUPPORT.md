| What you need | Where to go |
| --- | --- |
| Install the application or choose installer/portable packages | [README](../README.md#installation) and [latest release](https://github.com/googIeuser/NETWatcher/releases/latest) |

## Before opening an issue

Check the README and [existing issues](https://github.com/googIeuser/NETWatcher/issues) first. Include the NetWatcher version, Windows version, installation type, smallest reproduction, and expected/actual behavior. For monitoring problems, mention the check type (ICMP, TCP, or HTTP/HTTPS) and relevant settings without exposing private target details.

## Protect your network information

Diagnostics ZIPs, HTML/ISP reports, outage records, and screenshots may contain IP addresses, private hostnames, timestamps, or identifying network details. Do not upload complete logs or exports without inspecting them. Prefer short sanitized excerpts and synthetic target names; never include credentials, private keys, or certificates. See the [privacy policy](PRIVACY.md) for local storage and network requests.

Support is provided by the maintainer as time permits, without a guaranteed response or resolution deadline. NetWatcher can help record connection behavior, but it cannot resolve an ISP outage or replace your provider's support process.
