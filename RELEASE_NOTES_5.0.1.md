# NetWatcher 5.0.1

This maintenance release completes the 5.0 interface refresh after real Windows testing.

- The latency chart legend now says "No response" for an offline target instead of showing `0.0 ms`.
- Generated HTML and ISP evidence reports use the same paper-and-ink control-desk style as the app, including a print-friendly layout.
