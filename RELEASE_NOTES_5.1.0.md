# NetWatcher 5.1.0

The overview now centers on a live network map. Its nodes reflect the monitored targets and their current state. On smaller windows, the same information appears as compact rows. The sidebar keeps all six sections close at hand.

The new network-topology icon is included in the app, tray, executable, shortcuts and installer. Windows shortcuts use the same app identity as desktop notifications, and installation refreshes the per-user shortcut so a stale taskbar icon does not survive an upgrade.

Existing monitoring, history, reports and settings remain available. Measurements still stay on the local computer.
