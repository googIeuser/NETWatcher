# NetWatcher 4.0.8

NetWatcher 4.0.8 includes the dashboard, reports, and empty-state refresh from 4.0.7, with final desktop layout polish.

- Report action buttons use shorter, one-line labels.
- The target count badge uses a neutral accent instead of an alert color.
- The target address field and Add target button share one row on wider windows.

- `NetWatcher_Setup_4.0.8.exe`
- `NetWatcher_4.0.8_Windows_Portable.zip`
- Matching `.sha256` checksum files
