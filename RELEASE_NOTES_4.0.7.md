# NetWatcher 4.0.7

NetWatcher 4.0.7 refreshes the Windows interface to make connection health easier to read.

## Interface improvements

- The dashboard shows a clear monitoring state and waits for real measurements before displaying quality and metric values.
- Live metrics occupy one compact row on common desktop sizes, with a concise target status list beside the latency chart.
- Report options use compact rows so all three actions fit in a typical desktop window.
- Empty outage and custom target screens explain what will appear there.
- Static panels remain still when the pointer moves over them.
