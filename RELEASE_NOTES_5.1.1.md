# NetWatcher 5.1.1

Latency history now uses the interval that actually contains measurements within the selected range. A fresh session therefore displays a readable trace instead of squeezing its first points against the right edge. The telemetry header is clearer and the chart is shorter.

The chart initially shows four targets and offers a chooser for every other measured target. The dashboard lists six endpoints and opens the full Targets page when more are configured. Long names remain inside narrow chart cards.

The left navigation icons no longer draw a tile on selection, hover or press. Their labels still appear on hover, and keyboard focus retains a slim marker.
