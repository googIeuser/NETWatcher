# NetWatcher 5.0.0

NetWatcher 5.0.0 gives the Windows app a new network control desk while retaining its monitoring, outage history, reports and local-first behavior.

- Replaced the left sidebar with a responsive top navigation bar.
- Rebuilt the overview around a live signal panel, four telemetry readings, a latency chart and an endpoint list.
- Introduced a paper-and-ink interface with high-contrast signal accents in both light and dark themes.
- Reorganized settings into appearance/monitoring and startup/alerts groups, with Save always near the page heading.
- Kept offline and waiting states explicit until measurements arrive.
